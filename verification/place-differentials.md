# Differentials at a place (G09a-2a, G09a-2b) — 2026-09-19

Follows G09a-1 (`f2b650d`, private Linux run 35431502060). Two commits: the
generic local lemma (`61c51e3`, [LocalDifferentials](../lean/LocalDifferentials.lean))
and its application to the point places of the cover

## The problem this solves

An order of a differential at a place is defined by writing `ω = f·du` for a
uniformizer `u` and taking `ord_v(f)`. That is only a definition if a different
uniformizer gives the same answer, which needs the local statement that
`Ω[O_v⁄ℂ]` is generated by `du` — for every uniformizer, not for a chosen one.
Without it, any "order" would depend on choices, and so would the genus.

## Generic part (G09a-2a)

`localKaehler_span_eq_top`: let `A` be a local `R`-algebra with `Ω[A⁄R]`
finitely generated, whose residue field is generated by `R` (stated as: every
`x : A` differs from an element of `R` by an element of the maximal ideal), and
whose maximal ideal is `(u)`. Then `Ω[A⁄R]` is generated by `du`.

The proof is Nakayama over the local ring, in the form
`Submodule.le_of_le_smul_of_le_jacobson_bot`, applied to the span of `du`. The
only computation: `x = r + u·a` gives `dx = a·du + u·da`, and `u·da ∈ 𝔪·Ω`.

`localKaehler_span_congr` is the consequence: two generators of the maximal
ideal generate the same submodule, both being everything.

`localization_residue`: a residue field generated by the base survives
localization at a prime. The base has to be a field, since the proof inverts the
constant representing the denominator.

## Places of the cover (G09a-2b)

For the local ring `quadLocalRing h c d hd` of the point place `(c, d)`, which
is `primeLocalization` at the maximal ideal `ker (quadEval h c d hd)` of
`ℂ[t][W]/(W² − h)`:

- it is a discrete valuation ring (`quadLocalRing_dvr`, from G07b-2c);
- it is essentially of finite type over `ℂ`, so `Ω` is finitely generated;
- its residues are constants (`quadRing_residue`, `quadLocal_residue`), because
  the maximal ideals of `ℂ[t][W]/(W² − h)` are evaluation kernels at points of
  `ℂ²` (G07b-2b);
- hence `quadLocal_kaehler_span_eq_top`, `quadLocal_exists_uniformizer` and
  `quadLocal_kaehler_span_congr`.

`family_local_kaehler_uniformizer` states it for the family.

## Over the function field (G09a-2c)

`kaehler_span_map_eq_top` (generic): one generator of `Ω[S⁄R]` stays a generator
after a formally étale base change. Applied to `O_v → K`, which is a
localization, it gives `quadLocal_D_uniformizer_spans`: `du` spans `Ω[K⁄ℂ]` over
`K`. With G09a-1's `finrank = 1`, `du ≠ 0`
(`quadLocal_D_uniformizer_ne_zero`), so every differential is `f·du` for a
unique `f ∈ K` (`quadLocal_exists_coeff`).

`quadLocal_D_uniformizer_unit`: for two uniformizers `u, u'`, `du' = e·du` with
`e` a unit of `O_v` (stated as `e ∈ O_v` and `e⁻¹ ∈ O_v`).
`quadLocal_coeff_unit`: the coefficients read off from `u` and `u'` differ by
that unit. An order at the place, defined as the valuation of the coefficient,
is therefore independent of the uniformizer. The ℤ-valued order function itself
is not defined yet; it is introduced when G09b needs it.

All statements here use coefficients in `K`. Writing the regular differentials
as an `O_v`-submodule of `Ω[K⁄ℂ]` ran into two different `Module O_v Ω[K⁄ℂ]`
instances (`KaehlerDifferential.module'` versus the restriction along
`O_v → K`), which made rewriting fail; the field-coefficient formulation avoids
the ambiguity and says the same thing.

## Scope

The place at infinity (G07b-3) is not covered: it is not one of the point places
of `ℂ[t][W]/(W² − h)`, and the same argument has to be run in the chart at
infinity, which G07b-3 identifies with the conjugate family (G09a-2d). Still
undefined here: `ord_v` itself, `ord_v(dt)`, holomorphic differentials, the
genus (G09a-2e, G09b). No
divisor, Riemann–Roch or Riemann–Hurwitz statement is assumed anywhere.
